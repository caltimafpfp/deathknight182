# 死亡騎士182 V4 不裁切版

這個版本固定使用使用者提供的原始圖片：

- 檔案：`images/deathknight-original.png`
- 原始尺寸：565 × 572
- 圖片未重畫、未裁切、未修改人物
- 電腦版與手機版均使用 `object-fit: contain`

## 上傳方式

1. 解壓縮 ZIP。
2. 將資料夾內的 `index.html`、`css`、`js`、`images`、`README.md` 上傳到 GitHub 根目錄。
3. 同名檔案直接覆蓋。
4. 等 GitHub Pages 更新後按 `Ctrl + F5`。

## 修改按鈕連結

開啟 `js/config.js`，將 `#` 改成正式網址。
